# Half-Life-Starbie
Week 1 Project for Half Life Hack Club. Similar, but definitely not the same as, a Starboy

<img width="1322" height="911" alt="image" src="https://github.com/user-attachments/assets/4d866131-a821-49d7-9ddb-2cb50ee4ec22" />

The Starbie is something like a desktop Tomagachti. It can sense the environment, when it's being moved, and can be interacted with.
It's just like a miniature digital pet!

This is the starter project for week one of Half Life. I chose to do this option because this is the first time I have ever designed a PCB.
